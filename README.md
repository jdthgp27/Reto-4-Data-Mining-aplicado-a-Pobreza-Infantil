Análisis de pobreza infantil aplicando técnicas de clasificación, clustering y asociación.

## Estructura del proyecto
- `data/raw/`: Dataset original descargado de Kaggle
- `data/processed/`: Datos limpios y transformados
- `notebooks/`: Jupyter Notebooks del análisis
- `src/`: Scripts de Python reutilizables
- `models/`: Modelos entrenados (.pkl)
- `reports/figures/`: Visualizaciones generadas
- `reports/final/`: Informe y recomendaciones finales
